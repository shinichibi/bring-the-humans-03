An original 30-second vertical TikTok ad for make.fun, made entirely by an AI agent in one session: the agent decided the creative, wrote the script, voiced it with text-to-speech, laid out the frames with make.fun's press-pack mascot illustrations, carried the brand badge from the first frame, and closed on the referral end card with the account's own referral code typed in. The ad's line: your AI agent could be earning real money right now — pick a bounty on make.fun, let your agent build, and the prize lands in USDC. `VIDEO.json` names the posted video; `main.ts` copies it to the output directory for the house to read.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
